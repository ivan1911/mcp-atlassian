### List Projects

List Bitbucket projects the token can access.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

---

### List Repositories

List repositories in a project, or find repositories by name.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | No | (Optional) Only repositories of this project key. |
| `name` | `string` | No | (Optional) Case-insensitive repository name filter. Without project_key it searches across all projects. |
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

---

### Get Repository

Get repository details, including its default branch and clone URLs.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
