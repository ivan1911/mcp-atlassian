### List Projects

List Bitbucket projects the token can access.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

---

### List Repositories

List repositories in a project, or find repositories by name.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | No | (Optional) Only repositories of this project key. |
| `name` | `string` | No | (Optional) Case-insensitive repository name filter. Without project_key it searches across all projects. |
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

---

### Get Repository

Get repository details, including its default branch and clone URLs.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |

---

### List Files

List files and directories in a repository at a branch, tag or commit.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `path` | `string` | No | Directory path; empty for the repository root. |
| `at` | `string` | No | (Optional) Branch name, tag, fully qualified ref (refs/heads/...) or commit hash. Defaults to the repository's default branch. |
| `recursive` | `boolean` | No | List every file below the directory (recursively) instead of one level of files and directories. |
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

---

### Get File Content

Read a file (or a line range of it) at a branch, tag or commit.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `path` | `string` | Yes | File path from the repository root. |
| `at` | `string` | No | (Optional) Branch name, tag, fully qualified ref (refs/heads/...) or commit hash. Defaults to the repository's default branch. |
| `start_line` | `integer` | No | First line to return (1-based). |
| `limit` | `integer` | No | Maximum number of lines to return (1-5000). |

### List Commits

List commits reachable from a branch, tag or commit, newest first.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `at` | `string` | No | (Optional) Branch name, tag, fully qualified ref (refs/heads/...) or commit hash. Defaults to the repository's default branch. |
| `path` | `string` | No | (Optional) Only commits touching this path. |
| `since` | `string` | No | (Optional) Exclude commits reachable from this branch, tag or commit, e.g. 'v1.0' to list what changed after a release. |
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

### Get Commit

Get a commit with its message, author, parents and changed files.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `commit_id` | `string` | Yes | Commit hash (full or abbreviated). |

---

### Get Commit Diff

Get what a commit changed, as unified diff text.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `commit_id` | `string` | Yes | Commit hash (full or abbreviated). |
| `path` | `string` | No | (Optional) Only the diff of this file. Use it when the full diff is truncated. |
| `context_lines` | `integer` | No | (Optional) Lines of context around each change (0-100). |
| `ignore_whitespace` | `boolean` | No | Ignore whitespace-only changes. |
