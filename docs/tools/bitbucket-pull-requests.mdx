### List Pull Requests

List pull requests of a repository, filtered by state, people and text.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `state` | `string` | No | Pull request state. |
| `direction` | `string` | No | INCOMING: pull requests into this repository; OUTGOING: from it. |
| `target_branch` | `string` | No | (Optional) Only pull requests into this branch (from it when direction is OUTGOING). |
| `author` | `string` | No | (Optional) Author user slug. |
| `reviewer` | `string` | No | (Optional) Reviewer user slug. |
| `text` | `string` | No | (Optional) Text contained in the title or description. |
| `start` | `integer` | No | Index of the first item to return. Pass next_page_start from a previous response to get the next page. |
| `limit` | `integer` | No | Maximum number of items (1-100) |

### Add Pull Request Comment

Comment on a pull request: general, file, inline line, reply, or task.

<Note>This is a **write** tool. Disabled when `READ_ONLY_MODE=true`.</Note>

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `project_key` | `string` | Yes | Project key, e.g. 'PLAT' (case-insensitive). |
| `repo_slug` | `string` | Yes | Repository slug, e.g. 'billing-api'. |
| `pull_request_id` | `integer` | Yes | Pull request id. |
| `text` | `string` | Yes | Comment text in Bitbucket markdown. |
| `path` | `string` | No | (Optional) File path: comments on the file, or on a line of it together with 'line'. |
| `line` | `integer` | No | (Optional) Line number in the diff for an inline comment: the new-file line for ADDED/CONTEXT lines, the old-file line for REMOVED lines (see the hunk headers of the pull request diff). |
| `line_type` | `string` | No | (Optional) Kind of the commented diff line (default ADDED). |
| `file_type` | `string` | No | (Optional) Diff side: FROM (old) or TO (new). Inferred from line_type when omitted. |
| `parent_comment_id` | `integer` | No | (Optional) Reply to this comment id. |
| `as_task` | `boolean` | No | Create a task: a blocking comment that must be resolved. |
